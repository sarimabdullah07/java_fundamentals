# Java Fundamentals
 
A beginner-friendly collection of Java programs created while learning the core concepts of Java programming. This repository contains practical examples that cover conditional statements, loops, user input handling, control flow statements, and basic programming logic.
 
The purpose of this repository is to build a strong foundation in Java by practicing fundamental programming concepts through simple and easy-to-understand programs.
 
---
 
## 📚 About the Repository
 
This repository serves as a personal learning journal for Java programming. Each file focuses on a specific concept and demonstrates its implementation with practical examples. The programs are designed to help beginners understand Java syntax, program structure, decision-making statements, loops, and user interaction.
 
---
 
## 📂 Project Contents
 
### 1. Sarim.java
A basic introductory Java program used to understand:
- Java program structure
- Class creation
- Main method
- Output statements
 
This serves as one of the first steps in learning Java.
 
### 2. Input.java
Demonstrates how to take input from users using the `Scanner` class.
 
Topics covered:
- Importing packages
- Scanner object creation
- Reading user input
- Displaying entered values
 
### 3. If.java
Illustrates the use of the `if` statement in Java.
 
Concepts covered:
- Conditional execution
- Comparison operators
- Decision-making logic
 
### 4. IfElse.java
Shows how to use `if-else` statements to execute different blocks of code based on conditions.
 
Topics covered:
- True and false conditions
- Alternative execution paths
- Basic program logic
 
### 5. NestedIf.java
Demonstrates nested conditional statements where one `if` statement exists inside another.
 
Concepts covered:
- Multiple condition checking
- Hierarchical decision-making
- Complex logic implementation
 
### 6. SwitchCase.java
Introduces the `switch-case` statement used as an alternative to multiple `if-else` conditions.
 
Topics covered:
- Switch expressions
- Case labels
- Break statements
- Default cases
 
### 7. WhileLoop.java
Demonstrates the use of the `while` loop for executing code repeatedly while a condition remains true.
 
Concepts covered:
- Loop control
- Repetitive execution
- Condition checking
 
### 8. DoWhile.java
Shows how the `do-while` loop works in Java.
 
Topics covered:
- Post-condition loops
- Guaranteed first execution
- Loop repetition
 
### 9. ForLoop.java
Contains examples of the `for` loop used for controlled iteration.
 
Concepts covered:
- Counter-controlled loops
- Range-based repetition
- Efficient looping structures
 
### 10. ForEach.java
Demonstrates the enhanced `for-each` loop used for iterating through arrays and collections.
 
Topics covered:
- Array traversal
- Simplified iteration
- Collection processing
 
### 11. Break.java
Explains how the `break` statement is used to terminate a loop or switch statement prematurely.
 
Topics covered:
- Loop termination
- Flow control
- Program optimization
 
### 12. Continue.java
Demonstrates the use of the `continue` statement to skip the current iteration and move to the next one.
 
Concepts covered:
- Iteration control
- Selective execution
- Loop optimization
